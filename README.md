# 🩺 MedGuard AI

An AI-powered medicine safety checker that helps users determine whether a medicine is safe based on their medical conditions, allergies, and current medications.

---

## 📌 Features

- 🔐 User Registration & Login
- 💊 Medicine Safety Checker
- ⚠️ Drug Interaction Detection
- 🩸 Disease-Based Warnings
- 🌿 Allergy Detection
- 📜 Medicine Search History
- ⏰ Medicine Reminders
- 👤 User Profile Management
- 🛡️ CSRF Protection
- 👨‍💼 Admin Dashboard
- 📊 Reports & Analytics

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/hemalathalakku/MedGuard-AI.git
```

2. Import as a Maven Project

3. Create the MySQL database.

4. Run:

- database/schema.sql
- database/sample_data.sql

5. Configure database credentials in:

```
DBConnection.java
```

6. Build the project

```bash
mvn clean package
```

7. Deploy the generated WAR file to Apache Tomcat.
